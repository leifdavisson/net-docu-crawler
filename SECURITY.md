# Security Policy

## Supported Versions

Only the latest release version of **Net-Docu-Crawler** on `main` is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| >= 1.0  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability (such as credential handling, SSH transport validation, or command injection), please do **not** open a public GitHub issue. Report it privately to:

* **Email**: **leifdavisson@gmail.com**

Include a description of the vulnerability, reproduction steps, and affected environment details. We will acknowledge receipt within 48 hours.
