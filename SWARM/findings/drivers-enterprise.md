### 1. Netmiko Session-Prep & Read-Only Command Validation (`netmiko==4.8.0`)

Inspected installed Netmiko driver classes (`CiscoIosSSH`/`Telnet`, `CiscoNxosSSH`/`Telnet`, `CiscoXrSSH`/`Telnet`, `CiscoS300SSH`/`Telnet`, `JuniperSSH`/`Telnet`, `AristaSSH`/`Telnet`) via `inspect.getsource()` across `session_preparation`, `disable_paging`, `set_terminal_width`, `enable`, and `cleanup`:
- **Zero persistent config writes** across all 5 enterprise drivers and their Netmiko classes: all session-prep commands are strictly session-scoped (`terminal width 511`, `terminal length 0`, `terminal datadump`, `cli`, `set cli screen-width 511`, `set cli complete-on-space off`, `set cli screen-length 0`, `enable`, `exit`).
- **Invalid/problematic read-only commands on stated OS versions**:
  - `JuniperDriver`: `show ethernet-switching interfaces` (`| display json` & text) fails with `syntax error` on **52/52** real Junos ELS switches (`EX2300`/`EX3400`/`EX4100`/`EX4600`); ELS requires singular `show ethernet-switching interface`. `show lldp neighbors detail` fails with `syntax error` on **51/52** Junos 17.x/18.x switches before falling back to `show lldp neighbors`.
  - `AristaDriver`: `show port-channel summary | json` and `show port-channel summary` return `% Invalid input` on real EOS 4.37.0F (`show port-channel | json` / `show port-channel detailed | json` is valid).
  - `CiscoDriver` (NX-OS & legacy IOS): `show etherchannel summary` is invalid on NX-OS (requires `show port-channel summary`); `show mac address-table` fails on legacy IOS 12.x/891 without fallback to `show mac-address-table`.
  - `CiscoXRDriver`: `show hsrp summary` / `show vrrp summary` output aggregate counts on real IOS-XR (per-group tables require `show hsrp brief` / `show vrrp brief`).
  - `CiscoSMBDriver`: `connect()` redundantly re-sends `terminal datadump` after `CiscoS300Base.session_preparation()` already sent it, and omits `auth_timeout` (`include_auth_timeout=False`).
