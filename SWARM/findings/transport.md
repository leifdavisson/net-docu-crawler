### `NEEDS-DEVICE-DATA` Verification Wishlist (Read-Only Commands Only)

1. **FortiOS 6.4.x / 7.0.x / 7.2.x / 7.4.x (standalone & multi-VDOM, under `ReadOnlyAuditor` read-only `accprofile`) — validates `TR-01`**:
   - Non-interactive SSH `exec_command` test: `get system status` and `show full-configuration` (verify whether FortiOS SSH exec bypasses `--More--` paging without config writes, including with VDOMs enabled).
   - Interactive SSH PTY test (when console `output` is `more`): exact raw bytes of `--More--` prompt (CR/BS/ANSI padding) during `show full-configuration` for deterministic space-drainer stripping.
2. **Aruba AOS-CX 10.10+/10.13+ & Aruba Instant (IAP) 8.10+ — validates `TR-08`**:
   - Pre-auth TCP/22 SSH banner (`SSH-2.0-...`), initial CLI prompt, and read-only output of `no page` vs `no paging` and `show version` (confirm AOS-CX vs IAP distinction before `enable()`/`disable_paging()`).
3. **Cisco IOS-XR 7.x (ASR 9000 / NCS 5500 / XRv9000) & Cisco ASA 9.x (multi-context / HA) — validates `TR-11`**:
   - Exact initial prompts (`RP/0/RSP0/CPU0:<host>#`, `RP/0/RP0/CPU0:<host>#`, `<host>/<context>/<state>#`) and `terminal length 0` output.
4. **Palo Alto PAN-OS 10.2.x / 11.x (HA active/passive, custom non-`PA-` hostname) — validates `TR-08`, `TR-11`**:
   - Initial prompt (`admin@<hostname>(active)>`), `set cli pager off`, and `show system info` (disambiguate from Junos `user@host>`).
5. **MikroTik RouterOS 6.49.x & 7.14+ (large route/ARP table >4098 lines) — validates `TR-08`**:
   - Exact output of `/ip route print detail without-paging`, `/ip arp print detail without-paging`, `/interface ethernet print detail without-paging`, and `/export compact` (confirm zero pager prompts and syntax compatibility on both v6 and v7).
